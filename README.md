# 本地视频制作
这是什么：把旁白、画面和素材制作成本地视频，包含配音、字幕、封面与章节；不会替我选题或投稿。
我怎么用：把文案放进 `scripts/`、素材放进 `assets/`，告诉 AI 本期要做什么；它按阶段制作并让我听看预览。
怎么知道它正常：运行 `pwsh -File .\run.ps1 doctor` 和 `status` 看环境与进度；成片通过 `verify` 后仍要亲自观看。
坏了怎么提醒我：没有自动提醒，出问题直接跟 AI 说；`status`、`plan` 会指出过期或缺失的阶段。
让 AI 做什么：按现有工作流写画面、检查来源并制作本期视频；需要真实硬件或云端配音检查时使用对应入口；对外投稿由我决定。
完整命令、安装与恢复见 [当前工作流](docs/WORKFLOW.md)；画面写法见 [创作指南](docs/AUTHORING.md)，配音标记见 [配音指南](docs/VOICE.md)。
维护测试：`pwsh -File .\run.ps1 test`；它不替代有声预览、成片观看或真实配音验收。
